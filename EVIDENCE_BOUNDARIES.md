# Evidence and Interpretation Boundaries

1. **EXTERNAL_OBSERVED**: 18,000 original individual measurements are from usama0print/pqc-tls-benchmarking, pinned GitHub commit 7a74485a533da9ec7f4adccc644d05c69cf2ddae. They are not results generated by P1 or from our H1.0 hardware.
2. **MODELED_REPLAY**: EXP07 and the external GitHub trace replay substitute external observed TLS timing samples into assumed migration jobs. Priority, load and deadline inputs are not external measured SDN metadata. Their completion times are modeled.
3. **SINGLE_HOST_TLS**: Connected applications and OpenSSL handshakes ran on one host over loopback and TCP proxies. Reconnect interval is not end-to-end application downtime.
4. **SINGLE_HOST_LIVE_APP_TLS**: EXP08/EXP09A/EXP09B measured application-inter-response gaps during real TLS cutovers, but they did not measure physical Ethernet interruption or ONOS controller overhead. Run wall times also include test harness overhead.
5. **USERSPACE_CONTROLLED_TLS**: EXP10U controller exchanged OpenFlow-1.3-format messages with a custom switch implementation. This is not ONOS+OVS or a complete OpenFlow implementation. Its load signal is a configuration value, not a measured network utilization percentage.
6. **CODE_ONLY_LOCAL_TESTS**: EXP10 ONOS/OVS V1/V2/V3 are installation packages with local unit/security tests; 500-trial SDN and physical H1.0 execution results are absent.
7. **Independence**: Repeated jobs, trial blocks, replays and reuse of GitHub records must not be pooled or counted as independent physical experiments. Supplemental earlier ZIPs duplicate primary folders.
8. **Security**: The TLS groups represent X25519 classical and X25519MLKEM768 hybrid key exchange with classical ECDSA P-256 authentication; do not claim quantum-safe certificate authentication.
9. **Scientific conclusion**: End-to-end P1/P1-v1.1 superiority over B4 is unproven. Mechanism-level MBB benefit is a finding that applies to several scheduling methods. The locked research protocol is unchanged.
10. **Figures**: Conceptual hardware diagrams are illustrations, not photographs or installed-system evidence.
